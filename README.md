# PLataforma Educativa EDU_IA

Proyecto final de Ingenieria de Software bajo la metodología SCRUM

## Descripción 
EDU_IA es una plataforma web interactiva orientada al aprendizaje responsable, ético y práctico de la Inteligencia Artificial, estructurada en 3 módulos educativos con buscador por palabras clave, autoevaluaciones y panel administrativo CRUD.
